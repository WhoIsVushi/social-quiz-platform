# Screenshot gallery

Screenshots are intentionally not included in the initial repository upload. Add the final images to this directory, then replace the Screenshots section in the root README with the examples below.

Suggested files:

| File                  | View                 |
| --------------------- | -------------------- |
| `home.png`            | Homepage             |
| `templates.png`       | Template library     |
| `template-detail.png` | Template preview     |
| `dashboard.png`       | Owner dashboard      |
| `how-it-works.png`    | How-it-works section |

Use only demonstration content. Check that screenshots contain no real participant details, credentials, tokens, private browser tabs, or local environment files.

For `README.md`:

```markdown
## Screenshots

### Homepage

![Homepage](docs/screenshots/home.png)

### Template library

![Template library](docs/screenshots/templates.png)

### Template preview

![Template preview](docs/screenshots/template-detail.png)

### Dashboard

![Owner dashboard with demonstration data](docs/screenshots/dashboard.png)

### How it works

![How it works](docs/screenshots/how-it-works.png)
```

The same paths work in `README.tr.md`, which is also stored at the repository root. You may alternatively upload images directly through GitHub's Markdown editor and use the attachment URLs it inserts.
