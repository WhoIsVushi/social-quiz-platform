# Security

This is a portfolio project and is not operated as a public service. Included validation and security controls are described in [the security notes](docs/SECURITY.md); they are not an independent security certification.

Do not include passwords, environment files, database exports, tokens or personal information in public issues, pull requests or screenshots. Use a disposable local database when reproducing problems.

For a sensitive vulnerability, use GitHub's private vulnerability reporting feature if it is available on the repository. Otherwise use a contact channel explicitly published by the repository owner. Do not publish exploitable details or secrets in a public issue.

Before operating a public instance, review environment configuration, email delivery, database access, retention, backups and the draft legal pages. See [deployment notes](docs/DEPLOYMENT.md).
